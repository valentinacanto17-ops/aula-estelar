AULA ESTELAR — VERSIÓN WEB INSTALABLE

IMPORTANTE: Para instalar como app (PWA), sube TODOS los archivos de esta carpeta a un sitio HTTPS, por ejemplo GitHub Pages o Netlify. Abrir index.html directamente como archivo local NO permite instalarla como PWA.

En Chrome de Android: abre la dirección HTTPS > menú de tres puntos > Instalar aplicación o Agregar a pantalla principal (según el navegador). Abre una vez con internet para que se guarden los archivos; después prueba modo avión.

Puedes abrir index.html directamente para una prueba sin internet, pero la persistencia de datos desde file:// no es confiable y no debe usarse para registros reales.

Los datos se guardan LOCALMENTE en el navegador y no se sincronizan entre dispositivos. Exporta respaldos JSON regularmente desde el panel docente y verifica el archivo descargado. No uses nombres completos ni información sensible. El PIN es una barrera básica, no cifrado. No compartas archivos de respaldo: incluyen datos y PIN.

Antes de cambiar de versión, respalda en la versión anterior. Si instalas en otro origen o dominio, importa el respaldo: los datos NO migran solos.
